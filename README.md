# RadarJobs

Remote job aggregator + paid weekly digest. Static frontend (Cloudflare Pages),
Supabase for data/auth, a Python scraper that runs hourly on GitHub Actions.

| Piece | Where |
|---|---|
| Pages | `index.html` `jobs.html` `pricing.html` `account.html` `login.html` `signup.html` `legal.html` `privacy.html` `feed.html` |
| Shared UI | `site.css` (design tokens, plan/auth visibility), `boot.js` (pre-paint session), `app.js` (nav, zoom, live previews) |
| Feed | `jobs.json` + `rss.xml` at the repo root, regenerated by `scraper/scrape.py` |
| Auth / data | Supabase project `juijmkcfbjthohjpgflr` (`profiles`, `subscriptions`, `jobs`, `sponsored_jobs`, `digest_log`) |
| Payments | Paddle Billing — IDs go in `paddle-config.js`; webhook in `netlify/functions/paddle-webhook.mjs` |
| Weekly email | `supabase/functions/weekly-digest/index.ts` (Brevo) |

## How data flows

1. GitHub Actions runs `scraper/scrape.py` **hourly** → commits `jobs.json` + `rss.xml`.
2. `pg_cron` pulls that file at `:15` (`rj_fetch_feed`) and upserts it at `:20` (`rj_apply_latest`).
3. The frontend reads Supabase directly, with `jobs.json` as the fallback.

## Local

```bash
py -m http.server 8099        # then open http://127.0.0.1:8099/index.html
py scraper/scrape.py          # regenerate the feed (add --push to write to Supabase)
```

## Selling a pinned listing ($30/mo)

Paid rows live in `sponsored_jobs`, so the hourly feed refresh can never delete
them. They are pinned above organic results **only while they match the
visitor's search and filters**, with a "Sponsored" badge, and impressions/clicks
are counted.

```bash
cp .env.example .env          # paste SUPABASE_SERVICE_ROLE_KEY (server-side only)

py tools/sponsor.py add --title "Senior Backend Engineer" --company "Acme" \
  --url "https://acme.com/jobs/123" --logo "https://acme.com/logo.png" \
  --salary-min 120000 --salary-max 160000 --category engineering \
  --region worldwide --tags go,aws --blurb "Series A, remote-first" \
  --days 30 --weight 200 --email "hr@acme.com"

py tools/sponsor.py list
py tools/sponsor.py stats
py tools/sponsor.py extend <id> --days 30
py tools/sponsor.py pause <id> | resume <id> | rm <id>
```

`--dry-run` prints the payload without writing anything.

## Deploy

Push to `main` — Cloudflare Pages rebuilds and publishes automatically.
`_headers` (CSP, HSTS), `_redirects` and the clean URLs (`/jobs`, `/pricing`,
`/account`, `/feed`) ship with it.
